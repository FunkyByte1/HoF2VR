# Hand of Fate 2 VR - the Scenarios catalog (docs/scenarios.md). One scenario per line:
#   Tab | Label | steps
# Steps run in order, ';' between them: the mod's test-seam commands (as in the test harness) or the runner's own:
#   @map            the dev run's dungeon map, ready for a jump (a fresh run from the base save if it isn't)
#   @hub            the dev save at the challenge map (where a challenge and its deck are chosen)
#   @fresh mid|hub  always a fresh dev save from that base
#   @loadout        the weapon picked on the Fights tab (tab "Weapon") is equipped here
#   @until <state> [s]   wait for a game state (part of its name), default 60 s
#   @mapready       wait until the map takes jumps again
#   @wait <s>       wait seconds
#   @confirm        the encounter's card waits for Continue (A): pressed for the player
#   @here           runs where the player is (no dev save needed): tools like the hand check
# Labels show on the buttons: keep them short (about 16 letters). Tabs show in this order.
# Every scenario runs in the dev save (Safety/DevProfile.cs): the player's own save is never written.
